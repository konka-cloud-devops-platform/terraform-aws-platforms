# Terraform Projects

This repository contains **multiple real-world Terraform infrastructure projects** along with **reusable Terraform modules**.
Each project represents a **different hosting model or architecture pattern** commonly used in production environments.

The focus of this repository is on:

* Infrastructure design
* Traffic flow and networking
* AWS service integration
* Terraform best practices

* A **portfolio for recruiters and hiring managers**
